## Description

Writ is the financial permission layer for AI agents. AI decides what to buy. Writ decides whether it's allowed to spend. PayPal enforces the boundary.

You sign one sentence of intent. PayPal places an authorization hold. Agents, Writ's own, a team of specialists, or any MCP client, can only capture from that hold, and only when 13 deterministic rules (plain code, no model) allow it. Sub-agents only ever get narrower authority. Unspent money is voided back.

Then we ordered a compromised AI agent to steal: 16 attacks, 16 blocked. PayPal's own API confirmed $0.00 moved, before and after.

Everything runs in the PayPal sandbox: real API calls, test money. The paid data providers are simulated.
